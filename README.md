# CrossApp

Наскрізний проєкт із кросплатформного програмування.

## Предметна область

Замовлення.

Основні сутності: Customer, Product, Order, OrderLine.

Призначення: оформлення замовлень і підрахунок їхньої загальної суми.

Предметну область «Замовлення» обрано через її зрозумілу структуру та можливість послідовно розширювати функціональність програми в наступних лабораторних роботах.

## Лабораторна робота №7

Тема: звіти через LINQ.
Варіант: Замовлення.

### Реалізовані звіти

1. TopCustomers — топ клієнтів за загальною сумою замовлень.
   Оператори: GroupBy, Select, Count, Sum,
   OrderByDescending, ThenBy, Take, ToList.

2. OrdersAbove — замовлення дорожче заданого порога.
   Оператори: Where, OrderByDescending,
   ThenBy, Select, ToList.

3. ByStatus — кількість і сума замовлень за статусами.
   Оператори: GroupBy, Select, Count, Sum,
   OrderBy, ToList.

4. Totals — кількість замовлень, загальна сума,
   середній чек і максимальне замовлення.
   Оператори: ToList, Sum, Average, Max.

### Відкладене виконання

Where і Select створюють запит, який виконується під час
перебирання результату. Кожний виклик Count() виконує запит
повторно, тому після додавання відповідного замовлення до
локального списку кількість збільшується на один.
ToList() виконує запит і зберігає DTO в окремому списку.
Після очищення джерела повторний Count() повертає нуль,
а кількість елементів у збереженому списку не змінюється.

### Особливості

- Логіка звітів розміщена в Core.
- CLI відповідає за команди та виведення.
- Звіти повертають DTO.
- Топ клієнтів має додаткове сортування за ім’ям.
- Порожні колекції обробляються без помилок.
- Використовується LINQ to Objects.

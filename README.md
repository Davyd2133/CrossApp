# Лабораторна робота №6

Варіант: Замовлення.

## Тема

Доменні події, делегати Action/Func, лямбда-вирази.

## Реалізовано

- Сутності Order та OrderLine з перевіркою інваріантів.
- Інтерфейс IOrderStore.
- Сховище в пам'яті та JSON-сховище.
- Події OrderCreated, LineAdded, OrderConfirmed.
- Дані події: OrderId, Kind, LinesCount, Total, At.
- Перший підписник: консоль і logs/app.log.
- Другий підписник: лямбда-лічильник із замиканням.
- Відписка обробників через -=.
- Перевірка відсутності подій після невдалих операцій.
- Пошук через Func<Order, bool>.
- Core не виконує консольне виведення та логування.

## Запуск

Сховище в пам'яті:

dotnet run --project src/Cli

JSON-сховище:

dotnet run --project src/Cli -- --json

## Журнал

Повний шлях до logs/app.log виводиться під час запуску.
Каталог журналу створюється автоматично.
Повторний запуск дописує записи до наявного файлу.

## Демонстраційний сценарій

1. Створення замовлення.
2. Додавання двох позицій.
3. Відмова для від'ємної кількості та неіснуючого id.
4. Додавання третьої позиції.
5. Відписка журналу.
6. Підтвердження замовлення.
7. Пошук підтверджених замовлень із сумою від 1500 грн.
8. Відписка лічильника.
9. Зміна даних без підписників.
